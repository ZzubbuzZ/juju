`python brouillons/plan-de-bord/plan_bord.py` régénère le SVG et sa copie `folio-6-plan-de-bord-inkscape.svg` : mêmes dessins, couleurs du thème clair écrites en dur (Inkscape et la plupart des visionneuses ne lisent pas les variables CSS), fond dans un calque verrouillé, pastilles et trappes du plan dans le calque « Pastilles à placer », identifiées `pN-i` / `tN-i` (objet N, i-ème emplacement, en partant de 0). Pour placer les repères : déplacer les pastilles dans cette copie, sans toucher au reste, puis reporter leurs positions dans `objets.yaml` (X = 80 + 0,75 · x ; Y = 196,25 + 0,75 · y) ; ne pas retoucher les SVG, réécrits à chaque génération. Le script il reprend le bloc `<style>` du folio 0 et y ajoute les classes `amg`, `amg-f`, `amg-b`, `amg-d`, `amg-l`, `axe`, `flot`, `arr`, `halo`, `sol-b`, `sol-h`, `mat`, `teck`, `teck-j`, `vaig`, `vaig-f`, `obj`, `conf`, `tr`, `leg`, `ico-mot` et les classes de catégorie, les variables de couleur des textures et leurs motifs (`<defs>`), à reporter dans tous les folios et dans `page.py` à l'intégration.

Hors de `Electricité/` tant que l'emplacement définitif n'est pas décidé (proposé : `Electricité/livret/`, ou un dossier propre à l'armement) ; le vérificateur ne le contrôle donc pas encore.
